# Flipkart Product Data Analysis Using Python

## Project Overview

This project focuses on analyzing Flipkart e-commerce product data using Python to uncover insights related to product pricing, discounts, brands, categories, and customer ratings.

The objective is to transform raw product data into meaningful insights through data cleaning, exploratory data analysis (EDA), and data visualization.

## Project Objectives

- Analyze product pricing and discount patterns.
- Identify top-performing brands and product categories by product count.
- Understand the distribution of retail and discounted prices.
- Explore product ratings and their relationship with pricing.
- Create visualizations to communicate important findings.

## Technologies Used

- **Python** – Data analysis and processing
- **Pandas** – Data manipulation and cleaning
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical visualization
- **Jupyter Notebook** – Interactive analysis environment
- **Requests & BeautifulSoup** – Web scraping libraries included in the environment

## Project Workflow

1. Dataset loading and exploration
2. Data inspection and understanding
3. Data cleaning and preprocessing
4. Handling missing values and duplicate records
5. Feature engineering
6. Exploratory Data Analysis (EDA)
7. Data visualization
8. Insights and conclusions

## Key Analysis Performed

- Product price distribution
- Discounted price distribution
- Discount percentage analysis
- Brand-wise product distribution
- Product category analysis
- Price correlation analysis

## Key Findings

Based on the analyzed dataset:

- **Total products analyzed:** 19,922
- **Total columns:** 18
- **Average retail price:** ₹2,979.21
- **Average discounted price:** ₹1,973.40
- **Average discount percentage:** 40.52%
- **Maximum observed discount:** 96.53%
